# Parlay of the Day — ten formats (Fri Sep 4, 2026)

Chuck killed the first attempt: "that is garbage." He was right. It was the
same dark rectangle with a big amber number that every card we make is, and a
parlay is the one product with a NATIVE visual object — the slip. People
screenshot slips. Nobody screenshots a title card.

Generator: `scripts/parlay_cards.py` (pure PIL, cached logos, no network).
`--demo` renders all ten with today's parlay; `--spec parlay.json` for any other.

## The ten

| # | Format | What it is | Best for |
|---|---|---|---|
| 01 | slip | A betslip. Legs, prices, break-evens, payout. | The default. Reads as the object itself. |
| 02 | stub | Torn paper ticket, perforation, off-white stock. | Stands out hardest in a dark timeline. |
| 03 | math | 1.87 x 1.84 x 1.96 = 6.75, shown. | Nobody else posts the arithmetic. Teaches. |
| 04 | dots | 100 dots, 15 lit. | The only honest picture of a long price. |
| 05 | bars | Needed-to-break-even vs three coin flips. | One-glance version of the whole argument. |
| 06 | trip | Triptych, one team-colour panel per leg. | Colour. The only card here that isn't dark. |
| 07 | bug | Broadcast lower-third stack. | Reads as television, not infographic. |
| 08 | square | 1080x1080. | The crop phones actually show. |
| 09 | texts | Message thread joke. | FOURTH QUARTER register. Most screenshotted. |
| 10 | poster | Type to the edges, marks as furniture. | Loudest in a scroll. |
