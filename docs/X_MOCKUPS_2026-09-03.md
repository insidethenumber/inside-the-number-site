## What's different this time, in one line each

- Twelve *formats*, not twelve versions of one card.
- Real logos on every card that names a team (from our own 860-logo cache).
- A product screenshot for each sport — half of your reference set was
  screenshots of someone's own product.
- One quote-post companion, one GIF reaction, one AI image, one meme, one
  animated ticker — the Pipeline A formats that need no Canva at all.
- A credited split with the source baked into the pixels.
- Two mistakes caught by the process before they shipped (below).

## Two things the process caught

1. **"BYU -51.5 is the biggest number on the board" was false.** Virginia Tech
   is -55.5 and *opened* -50.5. My first query listed matches without sorting.
   The product screenshot (C8) exposed it — the board showed VT with a
   "MOVED 5" tag. C1 was rebuilt. Lesson written into the engine doc: sort
   before claiming a superlative.
2. **The 12-0 math was wrong in my head and right on the card.** I had LSU at
   78.9% (raw) before computing; de-vigged is 75.7%, which makes twelve
   straight 3.6%, not 5.9%. Computed, not recalled.

## Formats used, and what each one is for

| Format | Mockups | Job |
|---|---|---|
| THE NUMBER | C1, M2 | Stop the scroll with one absurd, true figure |
| LINE MOVEMENT (animated) | C2 | Motion; the open-to-now story in three seconds |
| TEAM CARD | C3 | The matchup, priced, with real marks |
| THE BOARD | C4 | The reference object people screenshot |
| THE HOLD / BREAK-EVEN | C5, M3 | Teach one thing about price |
| WTF NUMBER | C6 | The "wait, what?" post |
| QUOTE-POST COMPANION | C7 | Ride the viral clip legally |
| PRODUCT SCREENSHOT | C8, M4 | Show the product; carry the link |
| MEME / GIF | C9, C12 | Be a person, not a brand |
| PHOTO + NUMBERS | C10 | Premium hero for the big slate |
| AI IMAGE | C11 | When there's no real visual for the idea |
| CREDITED SPLIT | M1 | Use their data, keep our integrity |

## Tooling notes from the build

- **Canva's AI generation quota ran out** after six generate calls. Copy/edit
  of existing designs does not count against it, which is exactly why the
  brand-template route (§4 of the engine doc) is the right one: build each
  format once, then only ever edit.
- **Cloudinary image generation is at zero.** Premium models cost five credits.
- **The board generator gained a white plate** behind every team mark so
  same-colour logos read. Committed.
- **Eight CFB logos are missing** from the cache: ORE, TNST, MOST, UTU, WMU,
  NIU, IOWA, TENN. Run cache-logos tomorrow.
- **GIPHY is searchable from the browser** without an API. Good enough.
- **The product screenshot is the cheapest format we have** and it's the one
  that caught an error. It should be in the rotation daily.
